Forno Lume
==========

Open index.html in a browser. The demo runs as a static site in Slovenian, English and Italian. Menu categories filter the list and each dish opens a detail panel. The booking preview uses two sample time slots and generates a summary locally.

Forno Lume is fictional. The menu, prices and opening hours are examples. The booking preview does not collect personal details or make a reservation.

The demo uses local photographs. See assets/PHOTO_SOURCES.txt for their source notes.
